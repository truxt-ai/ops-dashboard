1.16.0 to 1.16.2. Each has one locked and installed copy. npm 11.12.1 generated
the lockfile; check-fix.mjs and resolved-versions.mjs both exited 0, with no
downgrades or changes to existing unrelated packages. Seven new transitive

The new tests call the project's `syncMetrics` and `probeUpstream` with real
Axios HTTP adapters and loopback servers. Coverage includes JSON POSTs, 307
redirects, cross-origin credential removal, explicit/authenticated and environment
proxy routing, NO_PROXY bypass, 2000/5000 ms timeouts and recovery. The fixed
upstream probe URL is retargeted by a request interceptor only in the local
fixture; no external upstream integration is claimed. The pollution case uses
the advisory's precondition of an already polluted Object.prototype, and
demonstrates a worker request accepting HTTP 503 at baseline (`Missing expected
rejection`) and rejecting it after the upgrade. Its unpolluted control passes
at both versions. An initial fixture run used a read-only prototype property;
that setup error is retained separately and is not red/green evidence.

Only this one selected vulnerability is demonstrated with a behavioral exploit
regression; closure of the other selected findings is supported by resolved
versions and both complete rescans, not 25 separate exploit reproductions.
Browser XSRF, streamed body limits and the full advisory matrix are not exercised
by these server-side application paths.

Independent QA has not run. Per the ticket's delivery instructions, the security
lead starts **Run sanity suite** through the product once the PR is open. CI runs
on Node 20; this local run uses Node 24.15.0. CI is left to the native gate and
is not awaited. There is no build script. Nothing was merged or deployed.
